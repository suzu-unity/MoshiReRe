# 立ち絵ポートレート・ワークベンチ

ブラウザーだけで、立ち絵シートから複数の切り出しを作るためのローカルツールです。画像は外部へ送信されません。

## 開き方

`index.html` を Chrome、Edge、Firefox などで直接開きます。インストールやビルドは不要です。

## 基本操作

1. 素材画像を画面左上へドロップします。複数画像をまとめて追加できます。
2. 「左半分」「右半分」または「＋追加」で切り出しを作ります。
3. キャンバス上で枠内をドラッグして移動し、四隅をドラッグしてサイズを調整します。空白部分または中ボタンのドラッグで表示をパンし、ホイールでズームします。
4. 黄色い丸を顔・目の基準位置へ移動します。破線は出力上の目標位置です。
5. 出力サイズ、命名メタデータ、形式を設定して書き出します。

比較オーバーレイでは、別の切り出しを半透明で重ね、左右反転して位置や大きさを比較できます。

## 保存と再リンク

「プロジェクトJSON」で切り出し設定とメタデータを保存できます。ブラウザーにも同じ情報だけを自動保存します。元画像は保存されないため、再び開いた後は元画像をドロップしてください。ファイル名とファイルサイズが一致すれば自動で再リンクされます。

## 書き出し

選択中の切り出しは PNG / JPEG / WebP で保存できます。「全スライスを順次書き出す」は、ZIPの代わりに各画像を順番にダウンロードし、最後に設定一覧の `manifest.json` を保存します。ブラウザーで複数ダウンロードの許可が必要になる場合があります。
