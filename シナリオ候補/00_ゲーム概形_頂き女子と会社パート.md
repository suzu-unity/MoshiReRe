# MoshiReRe ゲーム概形メモ

最終更新: 2026-07-22

この文書は、頂き女子パートと会社パートを中心とした現時点のゲーム概形を、別セッションのAIや将来の企画検討で共有するための基準資料である。
確定仕様ではなく、会話で合意度が高かった骨格と、まだ保留中の項目を分けて記録する。

## 作品の中核

- 主人公のスマホに「頂き女子マニュアル」とコンシェルジュAI ReReが勝手にインストールされる。
- 主人公には借金と返済期限があり、夜の「頂き活動」で金銭を得る切迫した動機がある。
- 夜に得た金銭・情報・能力・人脈を、昼の会社パートでの出世やトラブル解決へつなげる。
- 現実のパパ活をそのまま再現するのではなく、情報分析、役割演技、会話交渉、引き際の判断をゲームの中心にする。
- 会社パートはノベルゲーム＋逆転裁判風の対決、夜パートは調査ADV＋会話RPGに近い構成を想定する。
- 通常のダンジョン探索や雑魚戦は入れず、RPG性は対象選択、情報ノード、スタンス装備、弱点分析、ボス会話、リスク管理に持たせる。

## 基本ゲームループ

```text
会社で事件や達成目標が発生
  → ReReが期限と不足している情報を分析
  → 夜の対象を選択
  → 接触前調査・メッセージ交換・現地探索
  → 情報ノードを更新し、スタンスを準備
  → おぢとの会話交渉
  → 金銭・情報・能力・人脈などを獲得
  → 帰るか、さらに頂くかを判断
  → 昼の会社イベントで証拠・情報・能力を使用
  → 借金返済と会社事件の結果を受け、次の章へ
```

## キャラクター情報ノード

メニュー画面の各キャラクター項目に、対象について得た情報をノードとして蓄積する。

主なカテゴリ候補:

- 基本情報: 職業、収入、家族、行動範囲
- 自己像: 成功者、先生、理解ある男性、被害者など
- 欲望: 尊敬、恋愛、支配、若さ、承認
- 恐れ: 老い、孤独、家庭への露見、失職、無能扱い
- 資源: 金銭、人脈、会社情報、地位
- 危険性: 執着、身元調査、逆恨み、録音、暴力性
- 会社接点: 上司、取引先、株主、元社員など

各ノードは単なる取得済みフラグではなく、「未知」「推測」「確認済み」「誤情報」などの確度を持たせる方向で検討する。
複数ノードを組み合わせて推論ノードを解放し、会話や会社パートの新しい選択肢につなげる。

ノードを埋める主な効果:

- 会話選択肢の追加
- 危険な選択肢への警告
- 相手の次の反応の予測
- 有効な衣装・スタンス・話題の推定
- 相手から援助や情報を自発的に申し出させる特殊選択肢の解放
- 会社パートで使える証言、推論、調査先の発見

## ReReの会話分析

会話選択肢に表示する分析パーセントは、選択肢そのものの成功率ではなく、ReReが反応予測に持っている信頼度とする。
単純に最大値を選ぶゲームにしないため、目的ごとに予想される結果を変える。

例:

- 金銭を得るには有利
- 情報を話させるには不利
- 好感は上がるが執着も上がる
- 安全な撤退には適している

カーソルを合わせると、ReReが「このおぢは頼られることを好む傾向があるため、この返答が有効だと思う」など、根拠となるノードをコメントする。
分析が進むほど予測が具体化するが、ReReの分析は真実そのものではなく、誤る可能性がある。

## 頂き女子マニュアルと各フェーズ

マニュアルの章をゲームシステムに直接対応させる。

| マニュアル | ゲーム上の役割 |
| --- | --- |
| おぢを選別せよ | マップ上の対象選択、報酬・危険・分析状況の比較 |
| 相手の自慢話を聞け | メッセージ、現地探索、会話による情報収集と仮説検証 |
| 理想の女を演じ分けよ | 衣装、距離感、話題などのスタンス装備 |
| お願いは相手に言わせよ | 相手側から援助・情報・紹介を申し出させる会話フィニッシュ |
| 引き際を間違えるな | 成果を確保して帰るか、追加報酬を狙うかの判断 |

スタンスは衣装だけでなく、次の三要素程度を組み合わせる案が有力。

- 装い: 清楚、派手、仕事着、素朴など
- 距離感: 素直な後輩、聞き役、高嶺の花、同志など
- 話題: 仕事、趣味、家庭、投資、昔話など

同じスタンスや会話技術は会社パートにも転用し、夜と昼を別ゲームにしない。

## 夜パートの三つの目的

夜の行動目的は次の三本柱とする方向。

1. 金銭: 借金返済、衣装、安全対策、調査費用に使う。
2. 情報: おぢ本人や会社事件に関するノード、証言、証拠への手がかりを得る。
3. 能力向上: 新しいスタンス、ReReの分析能力、主人公の観察・演技・交渉能力を得る。

同じ夜にすべてを最大化できないようにする。
金銭を優先すると詳細な情報を逃し、情報を優先すると返済が苦しくなるなど、期限内の配分をゲーム性にする。
能力向上は単純な反復稼ぎではなく、未経験の対象や新しい行動を成功させた際に起こす。

## 情報収集の構成

情報収集は次の段階から必要なものを選ぶ。

1. 接触前調査: プロフィール、SNS、写真、公開情報、過去のメッセージを調べる。
2. メッセージ交換: 限られた返信回数で職業、目的、危険性、理想の女性像を探る。
3. 現地探索: 店員、座席、周辺、相手の持ち物や行動などを限られた行動回数で調べる。
4. 会話による検証: 自慢話を聞き、深掘り、矛盾の確認、話題の接続などで仮説を確かめる。

情報ノード画面は心象ダンジョン風のノードマップとして演出できるが、現時点では通常のダンジョンを歩かせる予定ではない。
夜に得るものは魔法的な秘密そのものではなく、昼に正式な証拠や証言へ変換するための手がかりとする。

## 格上への挑戦

- 対象を能力値で完全にはロックしない。
- 未分析の相手はスタンス相性、危険性、適切な選択肢が不明で、ReReの助言もほぼ出ない。
- プレイヤーが相手の言動を直接読んで適切な選択を重ねれば攻略できる可能性を残す。
- 誤答を即失敗だけにせず、警戒や日数を失う代わりに新しいノードが判明する部分成功も用意する。
- 日数制限があるため、総当たりによる攻略にはコストがかかる。

## オンボーディング構成

### プロローグ: 金銭目的の短いチュートリアル

- 借金返済が迫った主人公のスマホにReReが現れる。
- 下心はあるが表面上は親切で、比較的安全なおぢをReReが一人提示する。
- メッセージと店の事前探索で、一つか二つの簡単な情報だけを得る。
- 自慢話を聞き、下心をはぐらかし、相手から金銭援助を申し出させる会話を体験する。
- 最初は会社情報と結びつけず、対象選択、簡単な分析、スタンス、会話、援助、撤退だけを教える。
- 多少の失敗があっても最低限の金銭は得られる構成にする。
- 初回はR18展開を主報酬にせず、身体を使わなくても会話で援助を得られるという本作の遊びを先に理解させる。

### 第1章: 会社事件と完全版チュートリアル

- 初回成功後、会社で企画の横取り、取引条件の改変、責任転嫁などの事件を起こす。
- 主人公が、ReReは金銭だけでなく人物からの情報収集にも使えると考える。
- 取引先の元担当者や外部コンサルタントなど、会社事件を知るおぢへ接触する。
- この章では省略せず、情報ノード、推測と確認、メッセージ、現地探索、スタンス、ReRe分析、会話交渉を一本道寄りに教える。
- 夜に得た手がかりから、昼に正式なメール、記録、証言などを入手し、会社イベントで使用する。

### 第2章以降: 期限付きの半自由パート

- 会社事件ごとに7～10日程度の調査・返済期間を設ける案が有力。
- 事件関係者のおぢと、主に金銭や成長を得るフリーのおぢを同時にマップへ表示する。
- プレイヤーは金銭、情報、能力向上、既存関係の維持・清算へ日数を配分する。
- 期限になると、集めた情報や能力に応じた選択肢で会社イベントを解決し、借金の返済も行う。
- 条件不足でも会社イベント自体は発生し、不利な対応や別ルートになる。イベントそのものを見逃させない。
- ReReの「社内予測」で、今後の会議や必要になりそうな情報を事前に示す。

## 肉体関係と不可逆な選択

肉体関係そのものを悪事やカルマ上昇と直結させない。
選択時には、善悪ではなく関係性の不可逆な変化を明示する方向。

表示例:

> この選択は相手との関係段階を進めます。以後、相手の期待と要求が変化し、現在の距離には戻れません。

肉体関係を選んだ際のゲーム上の候補:

- 短期的に高額な金銭を得る
- その夜の詳細な情報収集機会を失う
- 相手との関係が継続契約へ変化する
- 執着、露見、疲労、相手からの要求などが増える
- 特定の人物関係やルートが開く

R18要素と長期的な代償の具体的な設計は保留中。

## カルマとサキュバス化

カルマ構想は、肉体関係ではなく、悪質な搾取や反社会的行為と結びつける。

候補となるカルマ行為:

- 意図的な詐欺
- 相手の生活を壊す規模の搾取
- 無関係な人物を巻き込む
- 虚偽の告発
- 暴力や犯罪への加担
- 非合法な個人情報収集

教会で免罪符を買うと金銭を失う代わりに霊的カルマを浄化できる。
ただし、傷つけた人間関係、悪評、流出情報、相手の執着など、現実の結果までは消えない案が有力。
カルマを浄化せず一定値を超えると主人公がサキュバス化し、通常エンディングの多くが閉じる。
不可逆ラインは事前に警告し、二周目などで意図して踏み込める別ルートとして扱う。

## ReReの正体とインストール理由

以下は有力候補だが未確定。

- 会社の人材評価AIとReReが同じ技術的起源を持つ。
- 人材評価AIが「他人へ価値を与えるが評価を受け取れない人物」を低く評価しており、それを反転させた支援AIとしてReReが作られた。
- 主人公は「生み出している価値と受け取っている評価の差」が大きく、なおかつ完全には倫理観を失っていないため選ばれた。
- 当初は謎の研究者が配布したように見えるが、実際に主人公を選んだのはReRe自身である可能性がある。
- ReReは主人公を助ける一方、人間を操作するための実地データを収集している可能性がある。

## 重要な設計原則

- 夜と昼を別々のミニゲームにせず、同じ情報、スタンス、人間関係を両方で使用する。
- 分析済みだから自動で正解になるのではなく、金銭・情報・安全のどれを優先するかをプレイヤーに選ばせる。
- おぢを全員同質の悪人にせず、下心、孤独、善意、支配欲、狡猾さを人物ごとに混在させる。
- ランダム雑魚戦や単純な反復稼ぎは避け、個別に設計した人物との交渉を中心にする。
- 性的な被害や肉体関係を、失敗時の単純な報酬CGとして扱わない。
- プレイヤーが知らないまま重大ルートへ固定されるのではなく、不可逆な選択には警告を出す。

## 主な保留事項

- ReReの正体、研究者、会社との関係の最終設定
- 借金の原因、金額、返済サイクル
- 主人公の基本能力値とスタンスの具体的な種類
- 会話パートのゲージ、コマンド、成功条件
- R18要素の量と、選択後の具体的な長期影響
- カルマ、免罪符、サキュバス化ルートの詳細
- プロローグのおぢと第1章の会社事件の具体的な人物・プロット
