# 立ち絵ポートレート・ワークベンチ

ブラウザーだけで、立ち絵シートから複数の切り出しを作るためのローカルツールです。画像は外部へ送信されません。

## 開き方

`index.html` を Chrome、Edge、Firefox などで直接開きます。インストールやビルドは不要です。

## 基本操作

1. 素材画像を画面左上へドロップします。複数画像をまとめて追加できます。
2. 「左半分」「右半分」または「＋追加」で切り出しを作ります。
3. キャンバス上で枠内をドラッグして移動し、四隅をドラッグしてサイズを調整します。枠は元画像の外へ移動・拡張でき、画像がない範囲は市松模様の透明余白として表示されます。空白部分または中ボタンのドラッグで表示をパンし、ホイールでズームします。
4. 黄色い丸を顔・目の基準位置へ移動します。破線は出力上の目標位置です。
5. 出力サイズ、命名メタデータ、形式を設定して書き出します。

比較オーバーレイでは、別の切り出しを半透明で重ね、左右反転して位置や大きさを比較できます。

## 表情差分の連続処理

「新規画像・スライスへ共通情報を自動継承」を有効にすると、キャラクター・衣装・向き・タグ・サブフォルダを直前の差分から引き継ぎ、連番を桁数を保ったまま増やします（`01` → `02`、`009` → `010`）。複数画像をまとめて追加した場合も追加順に進みます。

「次の差分を作成」は現在の切り出し・出力・ガイド・仕上がり設定を複製し、表情だけ空欄にします。<kbd>Ctrl/⌘+Enter</kbd> でも実行できます（入力欄の編集中は動作しません）。基本表情は日本語一覧から選べ、保存値には英字名が入ります。

「共通情報を全スライスへ反映」は、確認後にキャラクター・衣装・向き・タグ・サブフォルダだけを反映します。表情、連番、切り出し設定は変更しません。「前のスライスから引き継ぐ」では、必要なときだけ直前の共通情報と次の連番を設定できます。

バランスガイドには身体中心線、顔楕円、頭頂線、目線、顎線、肩線があり、スライスごとに位置・顔幅・不透明度を調整できます。編集画面とプレビューだけに表示され、書き出し画像には焼き込まれません。

「仕上がり倍率」とX/Yオフセットは、クロップ後の画像を中心基準で拡大縮小・移動します。100%・オフセット0%は従来の出力と同じです。画像外クロップや縮小で生じる余白はPNG/WebPでは透明、JPEGでは白になります。比較オーバーレイも透明余白を含む位置関係を維持します。

## 保存と再リンク

「プロジェクトJSON」で切り出し設定とメタデータを保存できます。ブラウザーにも同じ情報だけを自動保存します。元画像は保存されないため、再び開いた後は元画像をドロップしてください。ファイル名とファイルサイズが一致すれば自動で再リンクされます。

## 書き出し

選択中の切り出しは PNG / JPEG / WebP で保存できます。「全スライスを順次書き出す」は、ZIPの代わりに各画像を順番にダウンロードし、最後に設定一覧の `manifest.json` を保存します。ブラウザーで複数ダウンロードの許可が必要になる場合があります。
