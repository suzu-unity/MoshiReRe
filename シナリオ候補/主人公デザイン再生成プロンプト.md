# 主人公・罠美（Wanabi）固定デザイン仕様

## キャラクター固定要素

- 20代後半の日本人女性会社員。成人女性。
- 暗い焦茶に見える黒髪のストレートロング。長さは腰の少し上まで。
- 眉の近くで水平に揃えた重めの前髪。
- 左右非対称の横髪。本人から見て左側にだけ、胸元まで届く細く長い一房がある。
- 大きめの黒縁眼鏡。上辺は緩い長方形、下辺中央付近だけ僅かに角張った独特の形。細い金属製のつる。
- 眼鏡の本人から見て左側のつるに、ごく小さい金色の「上昇して直後に折れる折れ線チャート」意匠。
- 暗い琥珀色の瞳。色白。控えめで少し眠そうな目元。
- 細身すぎない標準的な成人女性の体格。
- 普段は少し猫背。内気に見えるが、表情が動くと欲や思い込みが分かりやすく顔に出る。
- 帽子は基本デザインに含めない。
- 眼鏡を外して美人化しない。全衣装で同じ眼鏡を着用する。

## 他AIで同一性を保つコツ

1. 毎回「固定要素」の全文を先頭へ入れる。
2. 最初に採用した三面図を、以後の生成でidentity/reference画像として必ず添付する。
3. 衣装・表情・画風を変える時も、髪の長さ、左の長い一房、眼鏡形状、左つるの金色チャート、瞳色を変更禁止として繰り返す。
4. 「眼鏡の女性」「黒髪ロング」だけで済ませず、非対称要素と眼鏡の形を必ず文章化する。
5. 左右反転が起きるモデルでは「viewer-right」ではなく「her own left side」と指定し、生成後に確認する。
